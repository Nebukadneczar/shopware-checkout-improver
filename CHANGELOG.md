# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2026-11-05

### Added
- Modern free shipping progress bar with smooth animations
- Configurable icon (truck, rocket, gift, star, none)
- Configurable border radius
- Three separate color options (background, fill, success)
- Improved accessibility with ARIA attributes
- Better visual design with CSS Custom Properties
- German and English snippets included
- Modern SCSS with smooth transitions and effects

### Changed
- Complete code rewrite with modern architecture
- New plugin name: `ShopwareCheckoutImprover`
- Updated CSS class naming convention
- Improved configuration structure
- Better documentation

### Fixed
- Cleaner code structure
- More maintainable template blocks
